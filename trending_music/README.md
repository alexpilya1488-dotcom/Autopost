# Трендовая музыка для нарезок

Положи сюда mp3/m4a/wav-файлы с треками — `edits_main.py` (через
`trending_music.py`) будет по кругу брать их для нарезок из фильмов.

**Важно про права.** Этот пайплайн сознательно использует реальные
трендовые песни (не royalty-free), потому что так решил владелец канала —
это copyright-контент, и его сюда добавляет и отвечает за легальность
человек, а не скрипт. Автоматического скачивания музыки в репозитории нет
и не будет. Практический риск: YouTube Content ID может приглушить звук в
ролике или отдать монетизацию правообладателю трека (это норма для таких
каналов), реже — прилетает страйк. Если трек с явными проблемами
(снят с площадок, под спором) — просто убери файл из папки.

Если папка пустая — `edits_main.py` не упадёт, а соберёт нарезку с
оригинальной звуковой дорожкой фильма (см. предупреждение в логах запуска).

Имя файла подпись/тайтл видео не выводит — используй любое.
